# Mabovula_Butchery_POE
POE for WEDE5020
This project is the complete POE for Mabovula Butchery, for the WEDE5020 module. This is a multi page website with HTML5, CSS3, and JavaScript that allows users to view meat products, place bulk inquiries, submit reviews, and use an online shopping cart
1. Project Overview & Folder Structure

The website is designed for a local butchery business. It covers product showcases, customer inquiries, feedback forms, and an interactive shopping cart
